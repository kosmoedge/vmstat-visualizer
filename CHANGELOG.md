# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

- Multiple column selection with `-c` flag
- Actual filenames in comparison legend (without full paths)

### Changed
- Enhanced README with usage examples and practical guidance
- Improved plot comparison logic

## [0.1.0] - 2025-01-XX

### Added
- Initial release
- Single file visualization for vmstat logs
- Support for CPU, memory, swap, I/O, and system load metrics
- PNG and SVG output formats
- File comparison mode
- Time-series plotting with matplotlib
